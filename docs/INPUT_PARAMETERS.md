# Input-dependent defaults

On a new or changed HDF5 input, Start row becomes 0, End row becomes the detector height (exclusive), and center-search row becomes height//2. Manual row and center limits follow the input dimensions. Automatic analysis defaults to All Slices and Middle Slice, and its Settings panel shows the current dimensions. Browsing and pasting paths are both supported. Editing parameters after loading the same input preserves those choices.
